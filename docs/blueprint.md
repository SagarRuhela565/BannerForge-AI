# **App Name**: BannerForge AI

## Core Features:

- Banner Generation: Use a generative AI tool to create a banner design based on a text description, resolution, and banner text.
- Progress Indicator: Display a progress bar during the banner generation process.
- Banner Display: Show the generated banner image on the page.
- Improvement Suggestions: Provide AI-powered suggestions on how to improve the banner design based on the original input and generated output.
- Input Form: Implement a form with text areas for banner description and text, and a field for resolution selection.

## Style Guidelines:

- Primary color: Vivid violet (#BE29EC) to evoke creativity and imagination, central to the banner creation process.
- Background color: Soft lavender (#F1E6FC), a desaturated tone of the primary to provide a gentle, unobtrusive backdrop.
- Accent color: Electric blue (#55C2F8) for interactive elements like buttons and progress bars, ensuring they stand out against the softer background.
- Headline font: 'Belleza' (sans-serif) for a blend of personality and aesthetic flair; body font: 'Alegreya' (serif) to ensure readability for generated advice and form descriptions.
- Utilize a clean, modular layout with clear sections for input, banner display, and improvement suggestions.
- Subtle animations during the banner generation and loading phases to maintain user engagement.
